# Spending view

Extend the collection's established warm canvas, forest accents, outlined category icons, typography, sidebar, controls, and dialogs. `spending-concept.png` provides the new summary/history composition. Preserve the existing Inventory wordmark, navigation icon family, and type scale when the generated concept differs.

Allowed copy: Spending; My space; A clearer picture of your purchases.; Total spent; recorded purchase(s); By category; Purchase history; Purchase; Category; Date; Amount. The month selector supplies its calendar label from data. Recorded purchases only. Items added as already owned do not count toward spending.

Layout: 240px sidebar, 48px desktop gutters, month controls in the header, two-column summary with exact total and category bars, then a bordered purchase table. Reuse existing tokens from globals.css. Below 760px, use the shared mobile navigation, stack the summary, and move date/category into purchase cells. Month navigation, history pagination, linked-item drawers, loading, retry, and empty states must work with actual account data.

Intentional adaptations: current logo and icon art rather than generated product photos; existing lighter typography; bars below category labels to accommodate narrow widths; actual account and records instead of concept examples; explicit profile currency and month labels. No comparison metrics, budgets, or fabricated data. This scaffold is read-only; standalone expense entry is a later slice.
